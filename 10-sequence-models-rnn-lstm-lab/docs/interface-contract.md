# Interface Contract

The React interface has six navigable views: Overview, Classify, Sequence Lab, Compare, Evaluation, and About. Each view supports loading, error, empty, and successful states without fabricating values.

Desktop, tablet, and mobile layouts retain navigation and primary actions. Controls use visible labels, keyboard focus, semantic buttons, and sufficient contrast. Animation is decorative and disabled under `prefers-reduced-motion`.

The evidence-status banner is persistent wherever fixture metrics appear. API failure never falls back to invented model output.
