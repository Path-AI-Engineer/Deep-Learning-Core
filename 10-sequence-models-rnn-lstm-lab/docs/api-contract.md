# API Contract

The service exposes fourteen versioned paths under `/api/v1`:

| Area | Paths |
|---|---|
| Runtime | `/health`, `/model-card`, `/models`, `/classes` |
| Samples | `/samples`, `/samples/{sample_id}` |
| Prediction | `/predictions/sample`, `/predictions/compare` |
| Evidence | `/evaluation/summary`, `/evaluation/errors`, `/evaluation/{model_id}` |
| Inspection | `/traces/sample`, `/labs/cell-trace`, `/labs/gradient-flow` |

Request and response schemas are generated by FastAPI in `/openapi.json`. Invalid shapes, identifiers, and cell types use structured 4xx responses. The service reports fixture provenance in metadata and prediction responses; it does not imply official benchmark performance.
