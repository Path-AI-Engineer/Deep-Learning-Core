# Model card — FashionCNN v1.0.0

Status: **pending trained artifact**

This document defines the approval contract. Numeric fields must be populated
from `artifacts/models/cnn/v1.0.0`; they must never be estimated manually.

## Intended use

Educational classification of FashionMNIST-like 28 × 28 grayscale catalog
images and inspection of elementary convolutional representations.

## Out-of-scope use

- General photographs or production retail imagery.
- Safety, medical, biometric or access-control decisions.
- Causal interpretation of feature maps.
- Online or user-triggered retraining.

## Architecture

Two convolution blocks with optional batch normalization, ReLU and max pooling,
followed by a compact fully connected classifier producing ten logits.

## Evaluation policy

The best epoch is chosen with validation loss. Accuracy, macro F1, per-class
metrics, confusion matrix and error records are computed once against the
isolated official test set. A fair MLP baseline uses the same split.

## Required evidence

- `metrics.json`
- `per_class_metrics.json`
- `confusion_matrix.json`
- `training_history.json`
- `comparison_with_mlp.json`
- `error_analysis.json`
- `split_manifest.json`
- `manifest.json`

Until those files are generated by the official training workflow, the model
must not be described as trained, evaluated or production-ready.
